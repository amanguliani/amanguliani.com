# Aman's A2UI (Agent-to-User Interface)

Welcome to my personal Agent-to-User Interface! This project transforms a traditional static portfolio website into an interactive, command-driven experience. 

## 🚀 Features

- **Agentic Routing**: Navigate the site using natural language commands in the search bar.
- **Auto-Suggest Search**: Real-time suggestions as you type to help you find what you're looking for.
- **Bulls Eye Word Game**: A fully playable, custom word-guessing game featuring a 600+ word dictionary, duplicate letter validation, and live dictionary API checking.
- **Glassmorphism UI**: A sleek, modern, and responsive aesthetic across all components.
- **Easter Eggs**: Keep clicking around... you might find something fun!

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (Custom Glassmorphism Design System)
- **Icons**: Lucide React & Custom SVGs
- **Language**: TypeScript

## 💻 Running Locally

To run this project on your local machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository** (or open the project directory):
   ```bash
   cd aman-a2ui
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   The terminal will output a local server URL (usually `http://localhost:5173` or `http://localhost:5174`). Open that link in your web browser to interact with the UI!

### Building for Production
To create an optimized production build, run:
```bash
npm run build
```
This will generate a `dist` folder that can be seamlessly deployed to any static hosting service like Vercel, Netlify, or GitHub Pages.
